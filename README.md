# Magistri Honorii Summa Quaestionum – digital sample edition (D.2 t.1)

Digital sample edition of titulus 1 *de simonia* (quaestiones 1–16) of the second distinctio of the
*Summa quaestionum* ‘De quaestionibus decretalibus tractaturi’ of Magister Honorius (working draft).

**Read the edition:** <https://nbecker3.github.io/honorius-summa-quaestionum/>

Text, critical apparatus and apparatus fontium follow the print edition: Magistri Honorii Summa Quaestionum
‘De quaestionibus decretalibus tractaturi’ (D.2), ed. Niels Becker, Waltraud Kozur, Karin Miethaner-Vent,
Würzburg 2021, <https://honorius-summa-quaestionum.com/>. TEI encoding and digital presentation: Niels Becker.

## Contents

- `tei/honorius_D2_t1.xml`: the edition in TEI-XML (TEI P5)
- `index.html`, `about.html`, `honorius.js`, `honorius.css`: the reading view (runs in any current web browser;
  no installation needed)
- `lib/`: CETEIcean and OpenSeadragon; `fonts/`: Junicode
